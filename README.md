# リズムのひろば

音を鳴らさず、2小節（4/4）のリズムを作るアプリ。依存パッケージ・ビルド不要です。

## 起動

```sh
cd /workspace/-
python3 -m http.server 8000 --bind 0.0.0.0
```

音符パレットから選び、マスをクリックして配置します。1マスが四分音符1拍、配置位置は半拍単位です。配置先と重なる音符は置き換わります。音符はドラッグで移動でき、移動先に音符がある場合は両方が収まるときに入れ替わります。「もどす」で直前の編集を戻せます。

全画面表示はテレビ提示向けです。Escで編集画面に戻ります。保存はブラウザのlocalStorageを使用し、同じブラウザ・同じアクセス元で保持します。名前を付けて何個でも別パターンとして保存できます。サーバーへの保存・端末間同期はありません。

## ダウンロードして使う

GitHubの「Code」→「Download ZIP」でダウンロードし、ZIPをすべて展開してください。
`rhythm-standalone.html` をChromeやEdgeなどで開くだけで使用できます。このファイルは単体で動作し、インストールやインターネット接続は不要です。

保存したパターンはブラウザに残ります。同じブラウザで同じ場所のファイルを開いてください。ブラウザのデータを削除すると保存パターンも消えます。
